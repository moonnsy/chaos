# Сюжетный пинок

Распакуй папку `plot-nudge` в `SillyTavern/data/default-user/extensions/` на устройстве, где запущен сервер. Если у тебя отдельный профиль, замени `default-user` на его имя. Проверь, что внутри `extensions/plot-nudge/` лежит `manifest.json`. Перезапусти SillyTavern, обнови страницу и открой **волшебная палочка → Сюжетный пинок**.

**Пнуть сейчас** запрашивает ответ персонажа. Если в поле ввода есть черновик, выбери **На следующий ответ** и отправь реплику обычным способом. Пинок передаётся в контексте одной генерации. При смене чата очередь и отсчёт сбрасываются.

**Случайно** выбирает событие, развитие сюжета или хаос. К этим режимам можно добавить таймскип. В режиме **Таймскип** срок обязателен. **Свой пинок** передаёт твоё пожелание к сцене.

Автопинки по умолчанию выключены. При включении случайный пинок срабатывает после указанного числа твоих ходов. Ручной пинок имеет приоритет и начинает отсчёт заново.
